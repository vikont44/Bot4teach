# Быстрый старт для пользователей

Краткое руководство для быстрого начала работы с ботом.

## Для всех пользователей

### Начало работы

1. Откройте бота в Telegram
2. Отправьте `/start` - вы будете зарегистрированы как студент
3. Отправьте `/help` - увидите все доступные команды

### Основные команды

| Команда | Описание |
|---------|----------|
| `/skills` | Показать все компетенции |
| `/questions` | Показать все вопросы |
| `/skill <id>` | Детали компетенции |
| `/question <id>` | Детали вопроса |

### Быстрый пример

```
/start                    # Регистрация
/skills                   # Смотреть компетенции
/skill abc123...          # Детали компетенции
/question def456...       # Изучить вопрос
```

## Для менторов

### Получение прав

Обратитесь к администратору для получения роли ментора:
```bash
python add_mentor.py <ваш_telegram_username>
```

### Команды управления

| Команда | Описание |
|---------|----------|
| `/add_skill` | ➕ Добавить компетенцию |
| `/add_question` | ➕ Добавить вопрос |
| `/edit_skill <id>` | ✏️ Редактировать компетенцию |
| `/edit_question <id>` | ✏️ Редактировать вопрос |
| `/delete_skill <id>` | 🗑️ Удалить компетенцию |
| `/delete_question <id>` | 🗑️ Удалить вопрос |
| `/link <skill_id> <question_id>` | 🔗 Связать компетенцию с вопросом |
| `/unlink <skill_id> <question_id>` | 🔗 Удалить связь |

### Быстрый пример добавления

```
/add_skill
Введите название: Python основы
Введите описание: Базовые знания Python
✅ Готово!

/add_question
Вопрос: Что такое Python?
Пример: Язык программирования
Приоритет: 5
✅ Готово!

/link <skill_id> <question_id>
✅ Связано!
```

## Полезные советы

### 💡 Как найти ID?

- В списке `/skills` или `/questions` (первые 8 символов)
- В деталях `/skill <id>` или `/question <id>` (полный UUID)
- После создания нового элемента

### 💡 Как отменить операцию?

Используйте `/cancel` во время любого диалога

### 💡 Формат ID

- Полный: `a1b2c3d4-5678-90ab-cdef-1234567890ab`
- Короткий: `a1b2c3d4` (тоже работает)
