## Начало работы

### Первый запуск

1. Найдите бота в Telegram по токену или username
2. Отправьте команду `/start`
3. Бот автоматически зарегистрирует вас в системе с ролью **студент**
4. Используйте `/help` для просмотра доступных команд

### Что происходит при /start

- Бот проверяет, зарегистрирован ли вы в системе
- Если нет - создает новую учетную запись с ролью "студент"
- Если да - показывает вашу текущую роль (студент/ментор)
- Выводит приветственное сообщение

## Роли пользователей

### 👨‍🎓 Студент (student)

**Роль по умолчанию** для всех новых пользователей.

**Что может делать:**
- Просматривать список компетенций
- Просматривать список вопросов
- Просматривать детали компетенций и вопросов
- Видеть связи между компетенциями и вопросами

**Что НЕ может делать:**
- Добавлять компетенции и вопросы
- Редактировать существующие данные
- Удалять компетенции и вопросы
- Создавать или удалять связи

### 👨‍🏫 Ментор (mentor)

**Административная роль** с полным доступом к управлению системой.

**Что может делать:**
- ✅ Все, что может студент
- ✅ Добавлять новые компетенции
- ✅ Добавлять новые вопросы
- ✅ Редактировать компетенции и вопросы
- ✅ Удалять компетенции и вопросы
- ✅ Связывать компетенции с вопросами
- ✅ Удалять связи

**Как стать ментором:**

Ментор назначается администратором системы через скрипт:
```bash
python add_mentor.py <ваш_telegram_username>
```

Или другим ментором (если такая функция будет добавлена).

## Команды для всех пользователей

### 📋 Просмотр информации

#### `/start`
Запускает бота и регистрирует пользователя в системе (если еще не зарегистрирован).

**Пример:**
```
Вы: /start
Бот: Привет! Я зарегистрировал тебя в системе.
     Используй /help для просмотра доступных команд.
```

#### `/help`
Показывает список всех доступных команд в зависимости от вашей роли.

**Пример:**
```
Вы: /help
Бот: 📚 Доступные команды:

     👁️ Просмотр:
     /skills - Список всех компетенций
     /questions - Список всех вопросов
     ...
```

#### `/skills`
Показывает список всех компетенций в системе.

**Вывод:**
- Порядковый номер
- Название компетенции
- ID компетенции (первые 8 символов)
- Краткое описание (если есть)

**Пример:**
```
Вы: /skills
Бот: 📋 Список компетенций:

     1. Python программирование
        ID: a1b2c3d4
        Описание: Знание основ Python...

     2. JavaScript разработка
        ID: e5f6g7h8
        Описание: Фронтенд разработка...
```

#### `/questions`
Показывает список всех вопросов в системе, отсортированных по приоритету.

**Вывод:**
- Порядковый номер
- Текст вопроса (первые 60 символов)
- ID вопроса (первые 8 символов)
- Приоритет вопроса

**Пример:**
```
Вы: /questions
Бот: ❓ Список вопросов:

     1. Что такое Python и для чего он используется?
        ID: 12345678
        Приоритет: 5

     2. Какие основные типы данных есть в Python?
        ID: 87654321
        Приоритет: 3
```

#### `/skill <id>`
Показывает детальную информацию о компетенции.

**Параметры:**
- `<id>` - ID компетенции (можно использовать первые 8 символов или полный UUID)

**Вывод:**
- Название компетенции
- Полный ID
- Описание (если есть)
- Оценка (если есть)
- Список связанных вопросов

**Пример:**
```
Вы: /skill a1b2c3d4-5678-90ab-cdef-1234567890ab
Бот: 📖 Компетенция: Python программирование
     ID: a1b2c3d4-5678-90ab-cdef-1234567890ab

     Описание: Знание основ Python, синтаксиса языка, 
               работы с типами данных, функциями и классами

     Вопросы (3):
     1. Что такое Python?
     2. Какие типы данных есть в Python?
     3. Как работают функции в Python?
```

#### `/question <id>`
Показывает детальную информацию о вопросе.

**Параметры:**
- `<id>` - ID вопроса (можно использовать первые 8 символов или полный UUID)

**Вывод:**
- Текст вопроса
- Полный ID
- Приоритет
- Пример ответа (если есть)
- Список связанных компетенций

**Пример:**
```
Вы: /question 12345678-90ab-cdef-1234-567890abcdef
Бот: ❓ Вопрос:
     Что такое Python?

     ID: 12345678-90ab-cdef-1234-567890abcdef
     Приоритет: 5

     Пример ответа: Python - это высокоуровневый язык 
     программирования общего назначения...

     Компетенции (1):
     1. Python программирование
```

## Команды для менторов

### ➕ Добавление данных

#### `/add_skill`
Запускает диалог для добавления новой компетенции.

**Процесс:**
1. Бот запросит название компетенции
2. Затем попросит описание (можно пропустить командой `/skip`)
3. Компетенция будет создана с ID

**Пример диалога:**
```
Вы: /add_skill
Бот: 📝 Добавление новой компетенции.
     Введите название компетенции:

Вы: JavaScript разработка
Бот: Введите описание компетенции (или /skip для пропуска):

Вы: Работа с JavaScript, DOM, асинхронностью и современными фреймворками
Бот: ✅ Компетенция добавлена!
     Название: JavaScript разработка
     ID: f9e8d7c6-5432-10ba-cdef-abcdef123456
```

**Пропуск описания:**
```
Вы: /add_skill
Бот: Введите название компетенции:
Вы: React разработка
Бот: Введите описание (или /skip):
Вы: /skip
Бот: ✅ Компетенция добавлена!
     Название: React разработка
```

#### `/add_question`
Запускает диалог для добавления нового вопроса.

**Процесс:**
1. Бот запросит текст вопроса
2. Затем попросит пример ответа (можно пропустить)
3. Затем попросит приоритет (можно пропустить, будет 0)

**Пример диалога:**
```
Вы: /add_question
Бот: 📝 Добавление нового вопроса.
     Введите текст вопроса:

Вы: Что такое React и в чем его преимущества?
Бот: Введите пример ответа (или /skip для пропуска):

Вы: React - это библиотека для создания пользовательских интерфейсов...
Бот: Введите приоритет (число, 0 - по умолчанию, или /skip):

Вы: 8
Бот: ✅ Вопрос добавлен!
     Вопрос: Что такое React и в чем его преимущества?
     ID: abc12345-6789-abcd-ef01-23456789abcd
```

**Пропуск параметров:**
```
Вы: /add_question
Бот: Введите текст вопроса:
Вы: Что такое JSX?
Бот: Введите пример ответа (или /skip):
Вы: /skip
Бот: Введите приоритет (или /skip):
Вы: /skip
Бот: ✅ Вопрос добавлен! (с приоритетом 0)
```

**Примечание о приоритете:**
- Приоритет - это число от 0 и выше
- Чем выше приоритет, тем важнее вопрос
- Вопросы сортируются по приоритету (от большего к меньшему)
- По умолчанию приоритет = 0

### ✏️ Редактирование данных

#### `/edit_skill <id>`
Запускает диалог для редактирования компетенции.

**Параметры:**
- `<id>` - ID компетенции для редактирования

**Процесс:**
1. Бот покажет текущие данные компетенции
2. Предложит выбрать поле для редактирования:
   - 1 - Название
   - 2 - Описание
   - 3 - Отмена
3. Попросит ввести новое значение

**Пример:**
```
Вы: /edit_skill a1b2c3d4-5678-90ab-cdef-1234567890ab
Бот: Редактирование компетенции: Python программирование

     Что вы хотите изменить?
     1 - Название
     2 - Описание
     3 - Отмена

Вы: 2
Бот: Введите новое описание:
Вы: Глубокое знание Python, включая ООП, декораторы, генераторы и работу с библиотеками
Бот: ✅ Компетенция обновлена!
```

#### `/edit_question <id>`
Запускает диалог для редактирования вопроса.

**Параметры:**
- `<id>` - ID вопроса для редактирования

**Процесс:**
1. Бот покажет текущие данные вопроса
2. Предложит выбрать поле:
   - 1 - Текст вопроса
   - 2 - Пример ответа
   - 3 - Приоритет
   - 4 - Отмена
3. Попросит ввести новое значение

**Пример:**
```
Вы: /edit_question 12345678-90ab-cdef-1234-567890abcdef
Бот: Редактирование вопроса: Что такое Python?

     Что вы хотите изменить?
     1 - Текст вопроса
     2 - Пример ответа
     3 - Приоритет
     4 - Отмена

Вы: 3
Бот: Введите новое значение для приоритет (число):
Вы: 10
Бот: ✅ Вопрос обновлен!
```

**При редактировании приоритета:**
- Нужно ввести число (0 и выше)
- Если ввести не число, бот попросит ввести снова

### 🗑️ Удаление данных

#### `/delete_skill <id>`
Удаляет компетенцию из системы.

**Параметры:**
- `<id>` - ID компетенции для удаления

**Важно:**
- Удаление компетенции также удалит все связи с вопросами
- Действие необратимо!

**Пример:**
```
Вы: /delete_skill a1b2c3d4-5678-90ab-cdef-1234567890ab
Бот: ✅ Компетенция удалена.
```

**Если компетенция не найдена:**
```
Вы: /delete_skill несуществующий-id
Бот: ❌ Компетенция не найдена.
```

#### `/delete_question <id>`
Удаляет вопрос из системы.

**Параметры:**
- `<id>` - ID вопроса для удаления

**Важно:**
- Удаление вопроса также удалит все связи с компетенциями
- Действие необратимо!

**Пример:**
```
Вы: /delete_question 12345678-90ab-cdef-1234-567890abcdef
Бот: ✅ Вопрос удален.
```

### 🔗 Управление связями

#### `/link <skill_id> <question_id>`
Создает связь между компетенцией и вопросом.

**Параметры:**
- `<skill_id>` - ID компетенции
- `<question_id>` - ID вопроса

**Что происходит:**
- Вопрос становится связанным с компетенцией
- Компетенция начинает включать этот вопрос
- При просмотре компетенции будет виден этот вопрос
- При просмотре вопроса будет видна эта компетенция

**Пример:**
```
Вы: /link a1b2c3d4-5678-90ab-cdef-1234567890ab 12345678-90ab-cdef-1234-567890abcdef
Бот: ✅ Связь создана!
     Компетенция: Python программирование
     Вопрос: Что такое Python?
```

**Если компетенция или вопрос не найдены:**
```
Вы: /link неверный-id 12345678-90ab-cdef-1234-567890abcdef
Бот: ❌ Компетенция не найдена.
```

**Если связь уже существует:**
- Бот сообщит об успешном создании (на самом деле связь уже была)

#### `/unlink <skill_id> <question_id>`
Удаляет связь между компетенцией и вопросом.

**Параметры:**
- `<skill_id>` - ID компетенции
- `<question_id>` - ID вопроса

**Что происходит:**
- Вопрос и компетенция остаются в системе
- Удаляется только связь между ними
- Вопрос больше не относится к этой компетенции

**Пример:**
```
Вы: /unlink a1b2c3d4-5678-90ab-cdef-1234567890ab 12345678-90ab-cdef-1234-567890abcdef
Бот: ✅ Связь удалена.
```

**Если связь не найдена:**
```
Вы: /unlink a1b2c3d4-5678-90ab-cdef-1234567890ab несуществующий-id
Бот: ❌ Связь не найдена.
```

## Часто задаваемые вопросы

### Как получить ID компетенции или вопроса?

ID отображается:
- В списке команд `/skills` и `/questions` (первые 8 символов)
- В детальной информации `/skill <id>` и `/question <id>` (полный UUID)
- После создания нового элемента командой `/add_skill` или `/add_question`

**Формат ID:**
- Полный: `a1b2c3d4-5678-90ab-cdef-1234567890ab`
- Можно использовать первые 8 символов: `a1b2c3d4`

### Можно ли использовать короткий ID?

Да! Бот принимает как полный UUID, так и первые 8 символов. Но рекомендуется использовать полный UUID для точности.

### Что такое приоритет вопроса?

Приоритет - это числовое значение, определяющее важность вопроса:
- **Чем выше число, тем важнее вопрос**
- При просмотре списка вопросов они сортируются по приоритету (от большего к меньшему)
- По умолчанию приоритет = 0
- Рекомендуемые значения: 0-10

### Можно ли связать один вопрос с несколькими компетенциями?

Да! Один вопрос может быть связан с любым количеством компетенций. Это позволяет использовать общие вопросы для разных компетенций.

### Можно ли связать одну компетенцию с несколькими вопросами?

Да! Одна компетенция может содержать любое количество вопросов.

### Что происходит при удалении компетенции?

- Компетенция удаляется из системы
- Все связи с вопросами автоматически удаляются
- Вопросы остаются в системе
- Действие необратимо!

### Что происходит при удалении вопроса?

- Вопрос удаляется из системы
- Все связи с компетенциями автоматически удаляются
- Компетенции остаются в системе
- Действие необратимо!

### Как отменить операцию во время диалога?

Используйте команду `/cancel` в любой момент диалога.

**Пример:**
```
/add_skill
Введите название: [вы передумали]
/cancel
❌ Операция отменена.
```

### Как стать ментором?

Свяжитесь с администратором системы. Ментор назначается через команду:
```bash
python add_mentor.py <ваш_telegram_username>
```

### Можно ли изменить роль самостоятельно?

Нет, изменение роли возможно только через администратора системы.

### Что делать, если бот не отвечает?

1. Проверьте, что бот запущен и работает
2. Попробуйте команду `/start`
3. Проверьте, правильно ли вы ввели команду
4. Убедитесь, что у вас есть права доступа (для команд ментора)

### Как посмотреть все вопросы для компетенции?

Используйте команду `/skill <id>` - в конце будет список всех связанных вопросов.

### Как посмотреть все компетенции для вопроса?

Используйте команду `/question <id>` - в конце будет список всех связанных компетенций.

## Ошибки и их решения

### ❌ "У вас нет прав для выполнения этой команды"

**Причина:** Вы пытаетесь выполнить команду ментора, не имея этой роли.

**Решение:** Свяжитесь с администратором для получения роли ментора.

### ❌ "Неверный формат ID"

**Причина:** Вы ввели ID в неправильном формате.

**Решение:** Используйте полный UUID или первые 8 символов. ID должен быть в формате: `a1b2c3d4-5678-90ab-cdef-1234567890ab` или `a1b2c3d4`

### ❌ "Компетенция не найдена" / "Вопрос не найден"

**Причина:** Элемент с таким ID не существует в системе.

**Решение:** 
- Проверьте правильность ID
- Используйте `/skills` или `/questions` для просмотра актуального списка

### ❌ "Ошибка при добавлении/редактировании/удалении"

**Причина:** Техническая ошибка на стороне сервера или базы данных.

**Решение:**
- Попробуйте повторить операцию
- Если ошибка повторяется, свяжитесь с администратором
