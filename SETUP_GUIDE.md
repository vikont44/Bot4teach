# Руководство по установке и настройке

## Шаг 1: Установка PostgreSQL

### Windows

1. Скачайте установщик PostgreSQL:
   - Перейдите на https://www.postgresql.org/download/windows/
   - Скачайте инсталлятор (рекомендуется версия 14 или выше)

2. Установите PostgreSQL:
   - Запустите установщик
   - Запомните пароль для пользователя `postgres` (по умолчанию)
   - Оставьте порт по умолчанию: `5432`
   - Завершите установку

3. Проверьте установку:
   - Откройте командную строку или PowerShell
   - PostgreSQL должен быть доступен через переменные окружения

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### macOS

```bash
brew install postgresql
brew services start postgresql
```

## Шаг 2: Установка зависимостей Python

```bash
pip install -r requirements.txt
```

## Шаг 3: Настройка переменных окружения

1. Скопируйте файл конфигурации:

   **Windows:**
   ```powershell
   copy env.example .env
   ```

   **Linux/Mac:**
   ```bash
   cp env.example .env
   ```

2. Откройте файл `.env` и настройте параметры:

   ```env
   # Конфигурация базы данных PostgreSQL
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=telegram_bot
   DB_USER=postgres
   DB_PASSWORD=ваш_пароль_от_postgres

   # Токен Telegram бота
   BOT_TOKEN=8486918034:AAFI7u2rLZm7eYEUhmtVOfNeKSD2lKcIQ_E
   ```

   **Важно:** Замените `ваш_пароль_от_postgres` на пароль, который вы указали при установке PostgreSQL.

## Шаг 4: Создание базы данных

Запустите скрипт создания базы данных:

```bash
python create_database.py
```

Этот скрипт автоматически:
- Подключится к PostgreSQL
- Создаст базу данных `telegram_bot` (если она не существует)
- Покажет сообщение об успехе или ошибке

## Шаг 5: Инициализация схемы базы данных

После создания базы данных, инициализируйте схему (создайте таблицы):

```bash
python init_database.py
```

Этот скрипт создаст все необходимые таблицы, связи и индексы.

## Шаг 6: Запуск бота

```bash
python bot.py
```

## Решение проблем

### Диагностика проблем подключения

Если возникают проблемы с подключением к PostgreSQL, используйте скрипт диагностики:

```bash
python check_postgresql.py
```

Этот скрипт проверит:
- Доступность сервера PostgreSQL
- Правильность настроек подключения
- Возможность установить соединение
- Статус службы PostgreSQL (для Windows)

### Ошибка NET HELPMSG 2185

Эта ошибка Windows обычно связана с проблемами сети или служб.

**Решения:**
1. Проверьте, запущена ли служба PostgreSQL:
   - Нажмите `Win+R`, введите `services.msc`
   - Найдите службу `postgresql-x64-XX` (XX - версия)
   - Убедитесь, что статус "Работает"
   - Если не работает, нажмите "Запустить"

2. Запустите диагностику:
   ```bash
   python check_postgresql.py
   ```

3. Проверьте брандмауэр:
   - Убедитесь, что порт 5432 не заблокирован
   - Добавьте PostgreSQL в исключения брандмауэра

4. Перезапустите службу PostgreSQL через PowerShell:
   ```powershell
   Restart-Service postgresql*
   ```

### Ошибка подключения к PostgreSQL

**Проблема:** `Ошибка подключения к PostgreSQL`

**Решения:**
1. Убедитесь, что PostgreSQL запущен:
   - Windows: Проверьте в "Службы" (Services)
   - Linux: `sudo systemctl status postgresql`
   - macOS: `brew services list`

2. Проверьте параметры подключения в файле `.env`:
   - Правильный хост (`localhost`)
   - Правильный порт (`5432`)
   - Правильное имя пользователя (`postgres`)
   - Правильный пароль

3. Проверьте, что база данных `postgres` доступна (системная БД)

### Ошибка: "База данных уже существует"

Это нормально! Скрипт просто сообщит, что база данных уже существует, и можно переходить к следующему шагу.

### Ошибка: "Неверный пароль"

Проверьте пароль в файле `.env`. Он должен совпадать с паролем пользователя `postgres`, указанным при установке.

### Не удается найти команду `createdb` или `psql`

Используйте Python скрипт `create_database.py` - он работает на всех операционных системах без необходимости добавления PostgreSQL в PATH.

## Проверка установки

После выполнения всех шагов, вы можете проверить работу базы данных:

```bash
python database/example_usage.py
```

Этот скрипт создаст тестовые данные и покажет, что все работает корректно.
